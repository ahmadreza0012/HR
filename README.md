# کارا — سامانه حقوق و دستمزد داینامیک

وب‌اپ فارسی برای مدیریت کارمندان، حضور و غیاب، شیفت‌ها، فرمول‌های نسخه‌بندی‌شده حقوق، پردازش ماهانه، خروجی Excel و Audit Log تغییرناپذیر.

## اجرای محلی

پیش‌نیازها: Node.js نسخه 22.13 یا جدیدتر و Docker Desktop.

```powershell
Copy-Item .env.example .env
npm install
npm run db:up
npm run dev
```

رابط در `http://localhost:3000` و API در `http://localhost:3001` اجرا می‌شود. مهاجرت دیتابیس و داده‌های اولیه در اولین اجرای API به‌صورت خودکار اعمال می‌شوند.

## جریان استفاده

1. در «کارمندان» پروفایل و حقوق پایه را ثبت کنید.
2. تعطیلات هفتگی و تعطیلی/شیفت هر تاریخ را در «تقویم و شیفت‌ها» ثبت کنید و انواع مرخصی و شیفت‌ها را در صفحه جداگانه «شیفت و مرخصی» مدیریت کنید.
3. حضور را دستی ثبت کنید یا در «گزارش‌ها و اکسل» فایل گروهی وارد کنید.
4. مولفه‌های پرداخت و کسورات را در «فرمول‌ها» بسازید.
5. ثابت‌های عمومی، واحد پول و روش گردکردن را در «تنظیمات» ثبت کنید؛ این ثابت‌ها در فرمول‌ها قابل استفاده‌اند.
6. در «پردازش حقوق» محاسبه ماهانه را اجرا، فیش‌ها را بررسی و دوره را نهایی کنید.
7. تمام ایجاد، ویرایش، حذف و پردازش‌ها در «تاریخچه تغییرات» قابل پیگیری هستند.

## قالب ورود Excel

ردیف اول باید شامل ستون‌های `کد پرسنلی`، `تاریخ`، `ورود`، `خروج`، `استراحت`، `مرخصی` و `نوع مرخصی` باشد. تاریخ با قالب `YYYY-MM-DD` و ساعت با قالب `HH:mm` وارد شود. فایل ابتدا پیش‌نمایش شده و کد پرسنلی، نوع مرخصی، ساعت، ورود/خروج ناقص و ردیف‌های تکراری را بررسی می‌کند؛ فقط در صورت اعتبار کامل به‌صورت تراکنشی ثبت می‌شود.

## امنیت محاسبات و حسابرسی

فرمول‌ها JSON ساختاریافته هستند و هیچ کد دلخواهی اجرا نمی‌شود. PostgreSQL با trigger مقدار قبل و بعد هر تغییر را ثبت می‌کند؛ Audit Log از طریق یک trigger حفاظتی غیرقابل ویرایش و حذف است. دوره قفل‌شده snapshot فرمول‌ها، تنظیمات، کارمندان، حضور و نتایج را نگه می‌دارد و تا بازگشایی رسمی قابل تغییر نیست.
